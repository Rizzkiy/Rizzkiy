## 🧑‍💻 About Me

I'm a student and developer from Indonesia interested in understanding how software, infrastructure, networks, and security work together.

I enjoy building things, breaking them in controlled environments, troubleshooting problems, and learning how systems work beneath the surface.

My journey started with software development and gradually expanded into Linux, networking, virtualization, self-hosted infrastructure, and cybersecurity.

- 🔐 Exploring cybersecurity through CTFs and hands-on labs
- 🐧 Working with Linux systems and server environments
- 🖥️ Building and maintaining homelab infrastructure
- 🐳 Deploying applications using Docker and container technologies
- 🌐 Exploring networking, virtualization, and self-hosted services
- ⚙️ Developing tools, web applications, and automation
- 🧪 Learning by experimenting, troubleshooting, and building real projects

> I don't just want to know how something works. I want to build it, test it, break it, and understand why.
